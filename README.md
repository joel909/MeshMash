# MeshMash

MeshMash is an Android application built with Kotlin, Jetpack Compose, and Material 3.

## Requirements

- Android Studio
- Android SDK 37
- An Android device or emulator running API 35 or newer
- JDK 11 or newer

## Clone and open

```bash
git clone https://github.com/joel909/MeshMash.git
cd MeshMash
```

Open the `MeshMash` directory in Android Studio and wait for the Gradle sync to finish. Then select a compatible device or emulator and click **Run**.

## Build from the command line

On Linux or macOS:

```bash
./gradlew assembleDebug
```

On Windows:

```powershell
.\gradlew.bat assembleDebug
```

The debug APK will be created under `app/build/outputs/apk/debug/`.

## Get updates

From the project directory, run:

```bash
git pull
```
